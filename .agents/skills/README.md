# Busala Skills

This directory contains specialized skills for the Busala School Management System project.

## Available Skills

### Core Development

| Skill | Description | Use When |
|-------|-------------|----------|
| `busala-architect` | System architecture, patterns, conventions | Understanding overall structure |
| `busala-frontend` | Next.js, React 19, TypeScript, Tailwind | Building UI components and pages |
| `busala-backend` | API routes, database queries, business logic | Creating/modifying API endpoints |
| `busala-api-dev` | Detailed API patterns (CRUD, validation, errors) | Implementing specific routes |
| `busala-database` | Prisma ORM, PostgreSQL, migrations | Database schema and queries |

### Specialized

| Skill | Description | Use When |
|-------|-------------|----------|
| `busala-auth` | Auth0 OAuth, sessions, RBAC | Login, logout, permissions |
| `busala-ui-design` | Design tokens, colors, spacing, patterns | Creating UI or styling |
| `busala-testing` | Vitest, React Testing Library | Writing tests |

## Quick Reference

```
Need to...                      → Use skill
───────────────────────────────────────────────────────
Build a new API endpoint        → busala-api-dev
Query the database              → busala-database
Add authentication              → busala-auth
Style a component               → busala-ui-design
Understand project structure    → busala-architect
Write a test                    → busala-testing
Create a page/component         → busala-frontend
```

## Usage

These skills are automatically available to Kimi Code CLI when working in this project.

To use a specific skill in a task:
```
@busala-database How do I add a new field to the Teacher model?
```

Or select the skill when starting a new task.
